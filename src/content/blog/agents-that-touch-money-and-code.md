An agent that only answers questions is easy to secure. An agent that issues refunds, enters bills or changes code is not. These are the controls every Quanta product is built on.

## Nothing changes without a person

The agent prepares the exact change and waits.

- In **Factum**, a person approves the refund, the bill or the email before it happens.
- In the **software foundry**, engineers review every change before it merges.

There is no mode where an agent quietly writes to your systems.

## Only the access the job needs

Each agent gets only the systems its job needs, and for each one whether it may **only read** or **also write**. An agent that reads your policy documents can't edit them.

## Everything on record

Every run is recorded: what started it, each step the agent took, what it proposed, who approved it and what it cost. When someone asks *"what did the agent do last Tuesday, and why?"*, there is an answer.

## Your data stays yours

- Each customer's data is **kept apart** from every other customer's.
- It's used **only to do the work you ask for**.
- It's **never used to train** a shared model.

## What we don't claim

We don't hold security certifications today, and we won't imply that we do. If you're running a security review, [we'll walk your team through](/#contact) the architecture and the data flows directly.
